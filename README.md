AI Sales Chatbot 

Overview
The AI Sales Chatbot is a Python-based application designed to interact with customers, answer product-related questions, provide service information, and assist with sales inquiries. It uses AI to generate relevant responses through a simple, user-friendly interface.

Features

AI-powered conversational responses

Customer query assistance

Product and service information

Interactive web interface

Real-time chatbot interaction

Tech Stack

Programming Language: Python

Frontend: Streamlit

AI Integration: AI/LLM API

Version Control: Git and GitHub

Installation

Clone the repository:

git clone https://github.com/anjimamurali/ai-sales-bot.git

Navigate to the project directory:

cd sankar-ai-sales-bot

Create and activate a virtual environment:

python -m venv .venv
.venv\Scripts\activate

Install the required dependencies:

pip install -r requirements.txt

Configure your AI API key using an environment variable or a .env file. Never upload API keys to GitHub.

Run the application:

streamlit run app.py

Usage

Launch the application in your browser, enter a question in the chatbot interface, and receive AI-generated responses to your queries.
